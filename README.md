# Pinboard
Pinboard — лёгкий сервис для тех, кто любит собирать изображения. Загружайте картинки, давайте названия, отмечайте любимые. Тёмный интерфейс, водопад карточек, поиск и автосохранение — всё под рукой. Работает в браузере без регистрации. Сегодня — личная коллекция, завтра — пространство для вдохновения. Красиво и просто.
